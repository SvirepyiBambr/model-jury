⚖️ Model Jury

One question. Every model. A verdict you can argue with.

Several AI models answer the same question independently, then the jury tally shows where they agree — and the dissent tells you what they don't.

Connect sends you to Pollinations to approve a key capped at 5 Pollen for 7 days; it stays in this tab. No key is embedded in this app — each visitor pays with their own Pollen. Manage keys.

How it calls Pollinations

Each juror is one independent request to POST https://gen.pollinations.ai/v1/chat/completions, sent in parallel with the visitor's own key and a model id chosen from GET https://gen.pollinations.ai/v1/models. The answers are parsed into a structured verdict; nothing is generated locally. See app.js.
